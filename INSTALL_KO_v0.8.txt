데빌즈 서드 Wii U 일본판 한글 패처 — v0.8 원본 전용 경량판

실행 파일: WiiU-Devils-Third-Kr-v0.8.exe
크기: 991,770,239바이트 (약 992 MB / Windows 표시 약 946 MB), 기존보다 28.55% 축소.
Windows 10/11 64비트에서 실행합니다. Python이나 별도 패치 프로그램은 필요하지 않습니다.

적용 방법
1. Cemu에서 게임을 종료합니다.
2. EXE를 실행하고 '폴더 선택'을 누릅니다.
3. code, content, meta가 들어 있는 데빌즈 서드 일본판 v0 게임 폴더를 선택합니다.
4. '한글 패치 적용'을 누르고 완료될 때까지 기다립니다.
5. Cemu의 Console language를 Japanese(일본어)로 설정합니다.
6. 게임 내 Language(언어)도 Japanese / 日本語(일본어)로 설정해야 한글이 나옵니다.
7. 게임 내 자막을 켜기(On)로 설정합니다.

- 원본 일본판 v0 전용입니다. 이전 한글판에 덮어쓰는 용도가 아닙니다.

- 설치 프로그램이 아닌 포터블 패처입니다. EXE를 다른 곳에 복사해 실행해도 됩니다.
